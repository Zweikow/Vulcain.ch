# Règle typographique : Tirets

- **JAMAIS de long tiret** : Ne jamais utiliser de tiret cadratin (`—` / em-dash) ni de tiret demi-cadratin (`–` / en-dash).
- **TOUJOURS utiliser des tirets simples courts** : Uniquement le caractère tiret standard `-` (tiret du 6, ASCII hyphen).
- Cette règle est stricte et s'applique à :
  - Tout le code source (textes, strings, constantes, JSX, templates, commentaires).
  - Tous les contenus éditoriaux (pages publiques, admin, légendes Instagram, descriptions produits).
  - Tous les messages de commit git.
  - Toutes les réponses fournies à l'utilisateur.
